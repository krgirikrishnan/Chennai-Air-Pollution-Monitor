# Chennai Air Pollution Monitor 🌿

Real-time Chennai air quality monitoring using Databricks, PySpark & OpenAQ API.

This project fetches live air pollution data for Chennai and gives alerts in Tanglish!

## 🚀 Tech Stack
- Databricks Notebook
- PySpark & Python
- OpenAQ API (Live Air Quality Data)
- GitHub

## ✨ Features
- Fetches real-time PM2.5, PM10, O3, NO2 data for Chennai (Lat: 13.0827, Lon: 80.2707)
- Calculates Air Quality Level (Good / Moderate / Bad)
- Gives funny Tanglish alerts:
    - "Mask podu da pa"
    - "Walk da pa"
    - "Fresh air da pa Giri!!"
